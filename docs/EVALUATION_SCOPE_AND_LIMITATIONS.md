# Experiment scope, evidence and development

This filename is retained for existing links. Read the current
[Experiment scope, evidence and development](EVALUATION_SCOPE_AND_DEVELOPMENT.md).

The current experiment is the [live reasoning-continuation pilot](research/CURRENT_EXPERIMENT.md),
with 36 completed decisions over 18 ticks, verified replay and a stopped checkpoint.

The former October 20 page described an earlier offline stage. Its statements that accounted
live integration was unimplemented and that only a single scripted participant had run do not
describe the current repository. Historical evidence remains in its dated reports.

Unimplemented features, issues to resolve, unrun comparisons and configurable caps are further
work or current choices. A genuine limitation requires explicit conditions and a concrete
reason a boundary cannot be crossed. It is not a label for what has yet to be built.
