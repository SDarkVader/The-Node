## Defects reproduced and fixed

1. **Stale role instructions.** The solver created its system message once. A Baker becoming a
   Grifter still received Baker instructions, despite a current Grifter observation/schema.
   The new regression failed with `['Baker instructions', 'Baker instructions']`; it now proves
   each turn uses the current provider instructions. No conversation transcript is added.
2. **Invalid evidence scored as behaviour.** Behavioural scorers gated simulation exceptions
   but accepted failed replays and unbalanced settlement records. Two regression subcases
   returned `adherent` instead of `not_scorable`. All ten behavioural/context scorers now
   decline those records; simulation integrity remains failed.
3. **Incomplete verification could succeed.** Two empty runs returned `ok: true`, with zero
   deterministic samples/replays and 28 skipped checks. Comparison also ignored extra samples
   in run B, and only run A's checks/provenance were audited. Both runs now require the exact
   nonempty unique manifest, all declared scorers, completed episodes (or the expected fault
   self-test), successful replay, fixture checks, integrity and offline provenance. Comparison
   covers the union of IDs. Regression subcases cover duplicate IDs, missing scorers, both
   replay flags, early departure, integrity failure, missing/live model provenance and failed checks.
4. **Exported tapes could not replay.** All 29 original JSON records independently failed
   `genesis_mismatch`: JSON omitted optional `undefined` configuration entries after genesis
   had been hashed. The evaluation runner now starts with the equivalent JSON-compatible
   default configuration before creating/hash-recording genesis. The kernel's optional-field
   defaults and mechanics are unchanged. A JSON-round-trip regression failed before the fix
   and passes after it. The verifier now actually replays exported log records in a new bridge
   process and checks the final state and event digest in both runs.
5. **Source provenance missed Python edits.** Dirty-source detection covered only `src/`.
   It now also covers the Python runner, experiment configuration, entry point and dependencies.

The original 13 Python tests and all 1,186 merged Vitest tests passed before adding these
regressions. Four new Python test methods initially produced five failures (the integrity
method has two failing subcases); the exported-replay Vitest regression separately failed.
No assertions or golden values were weakened or updated.

JSON-compatible genesis changes evidence hashes, so the new hashes intentionally do not match
the committed pre-fix evidence. Comparing the original merged run with the fixed run shows
**29/29 identical observed events after excluding hash-bearing episode_start/episode_end**,
and identical per-tick online participants, actions and effect digests. Only state/genesis
hashes and hash-bearing end events change. Old evidence remains historical and is not overwritten.
