## Purpose

Study how agents interpret an evolving social-economic world, use their own earlier thinking
and experience, and reconsider that thinking when circumstances and diary contents change.
Transcript memory is permitted. The world observation and diary still follow the game mechanics;
remembering an old observation does not make it current or grant another actor's private knowledge.

The owner intends to add memory bounds and degradation and study how previous thinking informs
future decisions. These are development and research tasks, not limitations on what the experiment
may become. The programme is exploratory; this documentation imposes no directional hypothesis.

## Evaluation ownership and separation

The run operator records requests, returned reasoning, decisions, receipts, validation and kernel
outcomes. It may comment on what returned reasoning says, clearly attributed as a comment; it
must not simultaneously improvise an evaluation or grade that reasoning or decision quality.

Interpretation belongs to a named evaluation framework/scorer or a human reviewer. If an assistant
runs an evaluation itself, identify the specific metric, definition, evidence inputs and result;
keep that evaluation separate from execution and from freeform reasoning comments. Do not turn
a comment, an exploratory stopping label, schema acceptance or a replay check into a quality score.

Inspect imported the continuation records; no reasoning-quality score or causal memory evaluation
was produced for this pilot. The original offline scorers have explicit rules for their own
fixtures; their scores must not be presented as grades of this live continuation run.

## Terminology

Use **current implementation** for what is built, **current configuration** for revisable choices,
**evidence so far** for what recorded runs support, and **further work** for implementation,
diagnosis, design and research still to do.

Use **limitation** only for a boundary that cannot be crossed under explicit conditions, with a
concrete reason. A missing feature, a defect, an unrun comparison or a configurable cap is not an
inherent limitation of the experiment. State the scope and reason of any actual boundary.

For example, a Git clone cannot contain private files never committed to it: the bytes are absent.
Secure state transfer remains possible work. This uncontrolled pilot's records alone do not identify
a causal memory effect; running an appropriate comparison remains possible work.
